# SBS Player

> Stage Back Sound Player

SBS Player is audio playback software for events usage, inspired by software such as QLab, MusicBee, and Multiplay.

## Features

- Registering and playing audio sources
- Support for major audio file formats (caf, mp4, mka, webm, ogg, wav, aac, alac, flac, mp3, opus)
- Fade-in and fade-out settings
- Individual settings for repeat, volume, playback range, etc.
- Repeat playback for multiple audio sources
- Saving to and loading from files
- Exporting to a folder (including the audio sources themselves)
- Clock display
- Sleep prevention

...and more

## Build

This software uses [mise](https://mise.jdx.dev/) to manage tools.

### Preparation

1. Install [mise](https://mise.jdx.dev/getting-started.html#installing-mise-cli)

2. Clone the repository

    ```bash
    git clone https://github.com/Keinsleif/sbsp.git
    cd sbsp
    ```

3. Install tools and packages（Rust, trunk, Pytho, etc...）

    ```bash
    mise bootstrap
    ```

### Build the software

1. Run build

    ```bash
    # Build "SBS Player"（including Web assets）
    mise run build_host

    # Build "SBS Player Remote"
    mise run build_remote
    ```

    `sbsp_host` and `sbsp_remote` are output to `target/release/`

2. Create installer and package for update (optional)

    ```bash
    mise run pack_host
    mise run pack_remote
    ```

    Files are output to `target/dist/`

> [!NOTE]
> To develop web build only, run `mise run dev_web` to launch dev server for browser.
