# Migration from v2 to v3

## Windows

### 1. Uninstalling the existing SBS Player

While it is possible to install v3 without performing this step, we recommend uninstalling, as files from the v2 application may otherwise remain.

- Open the "Settings" app, go to the "Apps" section, and select "Installed apps."
- Find "SBS Player" in the list of apps, then select "Uninstall" from the "⋯" menu.
- Follow the on-screen instructions provided by the uninstaller to complete the uninstallation.

### 2. Installing SBS Player v3

- Download the latest version of the installer from [Installation Instructions](../installation).

- If you did not perform an uninstallation, a confirmation dialog will appear; click "Repair."

- The installation will proceed automatically, and the latest installed version will open.

## macOS

If you have installed the application in the Applications folder via a .dmg file, it will be automatically overwritten by a newer version when you perform an installation using a .pkg file or a portable installation.

## Linux

Download the AppImage and overwrite the existing AppImage.
